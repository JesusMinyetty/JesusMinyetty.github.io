# Blog UX Project

Este proyecto es un blog diseñado con un enfoque en la experiencia del usuario (UX). A continuación se detallan los archivos y su propósito dentro del proyecto.

## Estructura del Proyecto

```
blog-ux
├── src
│   ├── index.html       # Página principal del blog
│   ├── about.html       # Página "Acerca de" del blog
│   ├── post.html        # Entrada de blog individual
│   └── styles
│       └── main.css     # Estilos CSS para el blog
├── README.md            # Documentación del proyecto
```

## Archivos Principales

- **src/index.html**: Este archivo contiene la estructura básica del HTML para la página principal del blog. Incluye el encabezado, el cuerpo y enlaces a las hojas de estilo.

- **src/about.html**: Proporciona información sobre el blog y su autor, manteniendo el mismo estilo que el resto del sitio.

- **src/post.html**: Representa una entrada de blog individual, incluyendo el contenido del post, comentarios y enlaces a otras entradas.

- **src/styles/main.css**: Define la apariencia de los elementos HTML, incluyendo tipografía, colores, márgenes y diseño responsivo.

## Instrucciones de Configuración

1. Clona este repositorio en tu máquina local.
2. Navega a la carpeta del proyecto.
3. Abre el archivo `src/index.html` en tu navegador para ver la página principal del blog.
4. Puedes navegar a las páginas "Acerca de" y las entradas del blog utilizando los enlaces proporcionados en la página principal.
